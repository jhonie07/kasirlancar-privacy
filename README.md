# KasirLancar — Kebijakan Privasi

Repositori publik ini hanya berisi halaman dan dokumen Kebijakan Privasi KasirLancar.

- Halaman web: `index.html`
- Dokumen Markdown: `PRIVACY_POLICY.md`

## Mengaktifkan halaman publik (GitHub Pages)

1. Buka **Settings** repositori ini.
2. Pilih **Pages** pada menu samping.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch **main** dan folder **/(root)**, lalu klik **Save**.
5. Tunggu proses deployment selesai. URL halaman akan menjadi `https://jhonie07.github.io/kasirlancar-privacy/`.

Pastikan halaman tersebut dapat dibuka tanpa login sebelum digunakan sebagai URL Kebijakan Privasi di Google Play Console.
